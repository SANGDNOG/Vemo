# Vemo identity

The original mark joins an audio signal to the letter V. The final source is `vemo-icon.svg`, rendered deterministically at all macOS icon sizes by `scripts/build-icon.swift`; `vemo-icon.png` and `Vemo.icns` are the app assets. They have a genuinely transparent exterior.

An initial concept was made with the built-in image-generation tool. Its exterior contained a baked transparency grid; the follow-up image edit failed because the upstream image provider was unavailable. The shipped icon is a new vector drawing, not a modified version of that raster.

Concept prompt: “A bold continuous white signal / audio waveform line flows naturally into an unmistakable capital V, on a deep indigo rounded-square macOS tile with a subtle violet-blue gradient and a tiny cyan endpoint. Simple silhouette, generous margins, no wordmark, front-facing graphic.”

The final vector assets and their rendering source are licensed with Vemo under MIT.
