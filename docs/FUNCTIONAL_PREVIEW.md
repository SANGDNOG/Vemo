# 기능 프리뷰 검증 — 2026-10-18

이 문서는 개발 브랜치의 기능 검증입니다. 공개 Mac DMG와 구분합니다. 기존 Android·Mac 디자인 소스, 사용자 녹음과 인증정보를 보존했습니다.

## Android와 Mac

- API 36 에뮬레이터의 기존 앱 데이터·Google 연결을 유지했습니다. 한국어 합성 음성 56.526초를 Android의 실제 완료·업로드 경로로 Google 테스트 폴더에 저장하는 검사 1건이 통과했습니다.
- Mac 검증 도구는 `oauth.storage / read-denied`로 기존 인증 저장소를 읽지 못했습니다. 이 녹음의 Google 자동 AI 왕복은 완료되지 않았습니다. 인증정보나 Keychain ACL은 변경하지 않았습니다.
- 별도 Yuna 한국어 합성 음성 43.772초를 Android 완료 녹음으로 만들고, Mac의 실제 가져오기·엔진·게시 경로로 Qwen ASR 1.7B, 정렬, 자동 제목, Qwen3.5 27B 상세 노트를 생성했습니다. 로컬로 전달한 결과를 Android가 식별자·해시·녹음일·전사·노트 검사 후 저장·재로드했습니다. Google 통신을 포함하지 않은 검사입니다.
- 100개/20개/20%, 표본의 일반화 제한, 학습·평가 분리, 정확도·재현율, 출시일 미정이 결과에 남았습니다. 일부 노트에는 원문에 없는 설명이 덧붙었습니다. 인용 검증은 요약의 모든 문장이 사실임을 보증하지 않습니다.
- 다른 합성 음색(Eddy)에서는 Qwen 전사의 기술 용어·숫자 오류가 발생하여 결과 게시를 중단했습니다. 한 합성 음성의 성공을 일반 정확도로 해석하지 않습니다.

Mac build 25 후보는 현재 엔진과 고정 로컬 인증서로 빌드·서명 검증했습니다. 설치된 build 24가 실행 중이며 화면 제어 서비스가 시작되지 않아 정상 종료 후 교체는 대기 중입니다. 공개 DMG와 사용자 상태는 그대로입니다.

## Windows 기능과 검사

x64·ARM64용 앱, 검증 도구, 모델 설치 도구를 각각 자체 런타임을 포함해 빌드했습니다. 서명 없는 포터블 프리뷰이며 설치 프로그램은 아닙니다. 사용법은 [Windows README](../windows/README.md)를 참고하세요.

macOS 호스트에서 코어 65개, 모델 설치 도구 12개, 독립 사례 39개를 포함한 116개 검사가 통과했습니다. 파일·폴더 경계, 원본 보존, 중복 모바일 식별자, 삭제 후 재수집 방지, 취소·재시도, 모델 선택 변경, 실패한 저장의 기존 결과 보존을 검사했습니다. 실제 Windows의 파일 시스템이나 GUI 검증과 구분합니다.

실제 macOS CPU에서 Windows용 .NET 코어와 Whisper large-v3-turbo·Qwen3.5 9B를 실행한 결과, 56.526초 음성을 55.955초에 전사·5개 주제별 노트·ZIP으로 처리했습니다. ZIP의 3개 파일과 원본 해시를 대조했습니다. 전사에서 `가정과 한계`가 `가전과 안개`로 잘못 인식되어 노트에도 남았습니다. 구조 검사가 전사 오류를 교정하지는 않습니다.

같은 합성 녹음 하나에서 공백·기호를 정규화한 문자 오류율은 Whisper small 8.87%, turbo 2.42%였습니다. 기본 전사 모델을 turbo로 선택하는 데 참고했으며, 사람 목소리·잡음·긴 강의에 대한 벤치마크는 아닙니다. 설치 도구는 선택한 고정 버전의 런타임·모델 크기와 SHA-256을 검증합니다. 별도 음성·노트 런타임에는 Microsoft Visual C++ v14 재배포 패키지가 필요하며, 공식 설치 경로를 Windows 안내와 ZIP 빠른 시작에 추가했습니다. 실행 호환성은 별도 확인이 필요합니다.

Windows Server 2022 평가판 x64 VM(.NET 10.0.13, 2 vCPU, 메모리 4GiB, 네트워크 차단)에서 **코어 검사 65개가 통과**했습니다. Unix 전용 프로세스 검사 1개는 명시적으로 건너뛰고 Windows용 취소·오류 종료 검사로 대체했습니다. 첫 실행에서는 고의로 저장을 막는 검사 6개가 운영체제별 예외 종류 차이로 실패했습니다. 허용하는 파일 접근 예외만 보완하고 기존 결과 보존·재시작 검사를 그대로 유지해 재검증했습니다.

깨끗한 Windows에서 음성 엔진이 `0xC0000135`로 종료되는 원인도 확인했습니다. Microsoft C++ DLL 네 개가 없었고, 공식 설치 파일의 SHA-256과 Microsoft Authenticode 서명을 검증해 설치한 뒤 실행이 성공했습니다. 이어 Whisper small로 56.526초 합성 음성을 **36.375초**에 전사하고 입력 해시가 보존됨을 확인했습니다. `인공지능`, `확률`, `학습` 등 기술 용어의 오인식이 남았습니다. 이 결과는 Windows CPU 실행 확인이며, 기본 turbo 모델이나 Windows 노트 생성의 품질·성능 검증은 아닙니다.

앱 프로세스는 Windows SYSTEM 설치 세션에서 15초간 실행을 유지했습니다. 실제 창·클릭·종료 흐름은 검증하지 않았습니다. Windows 11 GUI·ARM64 실행·NVIDIA 5070 Ti 실행이 확인된 것으로 해석하면 안 됩니다.
