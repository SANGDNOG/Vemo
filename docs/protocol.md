# Native app ↔ local engine protocol v1

Binding shared contract for the two implementation owners. User authorized implementation on 2026-10-11. Both sides use snake_case JSON keys. JSONL UTF-8, one event per line, line <=8MiB. stdout is JSON only; stderr has no recording content. Engine CLI: `python -m voice_memo_transcriber.service --state-root PATH --model-root PATH [--ffmpeg-path PATH]`.

Commands: `{request_id: string, protocol_version: 1, kind: string, payload: object}`. Events: `{sequence: integer, protocol_version: 1, kind: string, payload: object}`. `command_result` additionally carries payload `{request_id, ok, error?}`. hello and snapshot return `snapshot` payload `{jobs: [Job], engine_status: object}`. All mutation responses are idempotent by request_id.

Kinds: hello, snapshot, discover, import, enqueue, backfill, snapshot_ready, pause, resume, retry, retitle, set_recording_date, publish_ack, shutdown, download_models, set_policy. discover payload `{memos:[Memo]}`. import payload `{memo:Memo}`; an explicit import is queued, even on initial baseline. enqueue/backfill payload `{uuids:[string]}`. retry/retitle/set_recording_date payload includes `job_id`; retitle uses `{topic:string}` for manual topic or `{generate:true}` for regeneration; set_recording_date uses `{recording_date:"YYYY-MM-DD"}` and provenance user_supplied. pause/resume are global. set_policy payload `{ac_only:bool}` persists automatic power policy (default true), independently of manual pause. engine_status carries `ac_only`. Native sends policy before hello/discovery/import so no job starts under a stale setting; engine also checks actual AC power before processing when enabled.

Memo fields: uuid, recorded_at (ISO8601 timezone-aware string|null), recorded_at_source, original_timezone|null, duration_s|null, media_revision {size,mtime_ns}|null, completion_evidence (finished|active|unknown), source_kind (voice_memos|import), source_reference (stable opaque native registry ID), original_title|null. Private source paths must not be sent to the engine. Unclear completion evidence remains waiting; imports are explicitly finished after stable copy/decoding.

Job fields: id, uuid, topic|null, recording_date|null, recorded_at|null, duration_s|null, status, wait_reason|null, stage, completed_units|null, total_units|null, elapsed_seconds, artifact_path|null, audio_path|null, pcm_path|null, error|null, title_status, alignment_status, original_title|null. artifact_path is the engine-owned transcript JSON `{text,segments:[{start_s,end_s,text}],alignment_status}`. audio_path is an owned snapshot, never private source; pcm_path is the prepared owned mono16k WAV, optional for older jobs. QTA playback uses this PCM after native owned-path validation; other formats retain original snapshot playback. UI sentence/paragraph projection preserves authoritative text and raw alignment segments. Status values: unprocessed, waiting, preparing, transcribing, aligning, titling, saving, completed, needs_recording_date, failed, paused. job_changed payload `{job:Job}`.

snapshot_requested payload `{job_id,source_reference}`. Native checks source before/after device, inode, size and nanosecond modification/change stamps while copying, then reports the actual owned-copy revision pair (equal once stable; source stamps remain private). Engine compares these stamps to the owned file. Native sends snapshot_ready payload `{job_id,owned_path,revision_before:{size,mtime_ns},revision_after:{size,mtime_ns}}`. Engine validates path inside state root and hashes normalized PCM. Source-copy failures use snapshot_ready payload `{job_id,error:{code,message,recoverable}}` instead of a path.

publication_ready payload `{job_id,publication_id,manifest_path}`. Manifest `{schema_version:1,publication_id,job_id,uuid,recording_date,title,revision,files:[{name,path,sha256}]}`. Each path belongs to engine artifact root. Native publisher verifies source hashes and existing output manifest publication_id + all hashes; exact prior publication returns the same receipt without rewriting. New immutable revisions live under output/YYYY/MM/UUID/versions/<publication_id>/ and a manifest.json in UUID root is atomically activated. Finder/result-folder action opens active revision folder so Files shows normal TXT/MD files. Previous immutable revisions remain. No symlinks or partial root file set is authoritative.

publish_ack payload `{job_id,publication_id,receipt:{publication_id,output_manifest_path,artifact_hashes}}`, or `{job_id,publication_id,error:{code,message,recoverable}}`. Only successful validated ACK transitions engine job to completed. Engine replays publication_ready after crash; native detects existing exact output. Conflicts preserve user output and local artifacts. Timestamped filenames apply within every revision directory.

Model dirs inside model-root: asr/ for Qwen/Qwen3-ASR-1.7B, aligner/ for Qwen/Qwen3-ForcedAligner-0.6B, title/ for mlx-community/Qwen3-4B-Instruct-2507-4bit. models.json pins downloaded revisions. download_models launches explicit bootstrap download and emits `model_progress` payload `{model,downloaded_bytes,total_bytes|null,state,error?}`; no fake download percent. engine_status carries models_ready, model_status and paused. Operational inference uses local paths + offline/cache-only mode; never auto-download from ASR/title worker.

App runtime is ~/Library/Application Support/VoiceMemoTranscriber/runtime/bin/python3; scripts/install-runtime.sh builds and installs a noneditable project wheel into that runtime; scripts/build-app.sh builds only the native app. The app never starts the system Python by fallback. ffmpeg defaults /opt/homebrew/bin/ffmpeg. State root is App Support/VoiceMemoTranscriber; model-root is its models/. A single native app and engine writer operate; app crash triggers independent engine EOF/parent supervisor and model process group cleanup. Reopening a running app activates its GUI; restart starts a new engine/session from DB.
