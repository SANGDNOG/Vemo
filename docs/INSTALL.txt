Vemo — Apple Silicon preview.6 (0.2.1 build 36)

1. Drag Vemo.app into Applications.
2. Open Vemo. This preview is not signed with an Apple Developer ID or notarized.
   If macOS blocks first launch, open System Settings > Privacy & Security,
   find the blocked Vemo entry and choose Open Anyway, then confirm Open.
   Do not disable Gatekeeper or remove system security protections.
3. In Vemo settings, download the models and select a result folder.
4. For direct Apple Voice Memos access, add the installed Vemo.app to
   Privacy & Security > Full Disk Access, then quit and reopen Vemo.
   Direct database support has been checked on macOS 27.0.1 only.
   On other versions, use Import or the shared-files folder option.

Requirements: Apple Silicon, macOS 26.2+, 16 GB RAM recommended for transcription.
Base transcription, alignment and title models use approximately 8.8 GB.
Optional detailed notes use Qwen3.5-27B-4bit: an additional approximately 16 GB
download, with 24 GB RAM or more recommended. Allow extra storage for the app,
audio copies and generated results.
Models are downloaded on demand; audio, titles and notes are processed locally.

For Google Drive, Dropbox or OneDrive, select actual Mac-synced folders:
Vemo/Recordings for input and Vemo/Notes for output. Keep input audio available
offline. Share recordings from iPhone Voice Memos to the input folder. Vemo
saves transcripts and cited note Markdown in the local output folder; your
Drive sync app handles uploads. Input and output must be separate folders.
Click Notes to view the summary, original highlights and keyword groups.
Older completed transcripts can generate notes without transcribing again.
