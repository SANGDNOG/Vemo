# A Native White 적용 점검 — 2026-10-18

승인된 A 시안의 Android 16개·Windows 21개 화면 상태와 IMPLEMENTATION_HANDOFF를 대조했다. B/C는 비교용이다. 최근 요청한 재생 조작·폴더 접기·둥근 대화상자를 우선하며, 원본을 보존한 `feat/native-white-design-20261018`에서 작업했다.

**판정: 기존 기능에 연결할 수 있는 UI 누락을 보완했다. 전체 시안의 기능·픽셀 일치 완료는 아니다.** 아래의 구현은 소스와 빌드 근거이며, 실행 미검증을 별도로 표시한다.

| A 화면 | 이번 최종 상태 | 남은 차이·검증 |
|---|---|---|
| library | 승인 아이콘/색상, 간결한 목록, 작은 동기화, 하단 녹음 액션 | 제목 검색만 지원; 실제 작은 화면 검증 필요 |

| error | 실제 상태·복구/재시도 안내; 이전 결과 보존 | 오류 원인을 임의로 네트워크 오류로 분류하지 않음 |
| sync-wait | 업로드 전과 PC 결과 대기 분리, 실제 확인 액션 | 클라우드 연결/PC 처리 완료를 추측하지 않음 |
| processing | 실제 로컬 상태와 결과 대기 표시 | 원격 단계/백분율 계약 없어 시안의 숫자는 표시 안 함 |
| selection | 기본 디자인 적용과 분리된 확장 | Android 다중 선택 미구현 |
| trash | 기본 디자인 적용과 분리된 확장 | 기존 숨김 유지; 복원 가능한 휴지통 미구현 |

재생 트랙은 8dp, 탐색 영역은 최소 56dp로 키웠으며 작은 아이콘과 48dp 터치 영역을 유지한다. 폴더 접기는 녹음 배정/선택을 바꾸지 않는다. 포커스는 안정적인 액션 키로 복원하고 모달·다른 렌더·Activity 종료 중에는 배경으로 옮기지 않도록 보완했다. 실제 TalkBack 동작은 아직 미검증이다.

## 영구 삭제 실패 보완

삭제 전에 Purged tombstone과 미완료 오류를 저장하고, 소유 파일 삭제 성공 후에만 오류를 지운다. 실패 항목은 휴지통에서 재시도할 수 있고 재시작 시에도 정리를 재시도한다. 일부 파일이 사라진 항목을 복원/처리/내보내기하지 않는다. 기존 symlink/reparse 보호와 모바일 중복 가져오기 차단을 유지한다. 외부 원본·이미 내보낸 ZIP은 삭제 대상이 아니다.

회귀 테스트는 수정 전 6개 실패/1개 통과, 수정 후 7개 통과했다. 실제 Windows ACL·열린 파일 잠금·디스크 장애는 별도 검증이 필요하다.

## 검증 결과와 한계

- Android 0.1.11/versionCode 13: APK, JVM 단위 테스트 51개, lint 오류 0/경고 30, 계측 테스트 APK 컴파일 통과. UI 계측은 실행하지 않았다.
- API36 emulator-5554에 업데이트 설치. 녹음·결과·라이브러리 파일 7개 설치 전후 동일. 인증/데이터 초기화 없음.
- Windows Core 72개, Provision 12개, Python 패키징 검사 7개 통과. x64/ARM64 앱·검증 도구·설치 도구 6개 ZIP 생성 및 SHA-256/ZIP 무결성 확인.
- Team2 Android 최종 검토는 사용량 제한으로 중단되어, 사전에 알린 test_debug_pro 경로로 대체했다. 포커스 문제를 추가 발견해 보완했다.
- 화면 제어는 `Sky Computer Use native pipe startup failed`로 연결되지 않았다. 소스/빌드 통과를 실제 입력·화면 검증으로 대신하지 않는다.
- Android 360dp/600dp/가로/200% 글꼴/TalkBack와 Windows 실제 실행/DPI/Narrator/파일 대화상자 검증은 남아 있다.
- 과거 사용자의 “재생됨” 확인은 0.1.8 버전의 증거이며 이번 전체 화면 일치 확인이 아니다.
