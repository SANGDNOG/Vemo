# Android 상태 화면 보완 — 0.1.12-native-white

2026-10-18 사용자가 제공한 PC 대기/연결 오류 시안을 기준으로 수정했다. Windows는 별도 작업 중이므로 이번 변경에서 제외했다.

## 화면 변경
- 구름·삼각 경고 벡터를 추가했다. 상태 영역은 전체 너비 중앙 정렬, 최소 높이 240dp, 아이콘 36dp, 옅은 #B5AFC4, 제목 17sp, 설명 12sp/줄간격1.8이다.
- 설명·버튼 사이 21dp를 두고 작은 중립색 라운드 버튼과 최소48dp 터치 영역을 유지한다. 높이는 콘텐츠에 따라 늘어나고 기존 상세 스크롤에 포함된다.
- PC 결과 대기, 업로드 대기, 실제 동기화 중, 연결/인증/충돌/검증 오류, 중단 녹음 복구, 빈 전사/노트, 녹음만 저장된 상태를 점검했다.
- 빈 전사·노트와 녹음만 저장된 안내도 공통 중앙 상태 영역을 사용한다. 상세 진단은 ‘상태 자세히’에서 펼치며 이전 결과를 가리지 않는다.
- 브랜드 PNG는 기존 승인 자산과 동일함을 확인했다.

## 동작 보완
이전에는 uploaded 플래그가 있으면 실제 동기화 실패 이후에도 PC 결과 대기가 먼저 보였다. 앱 수준의 연결 준비 실패는 message에만 남아 상세 화면에는 나타나지 않았다.

SyncFeedback은 실제 시도 대상 녹음 ID별 오류를 메모리에 보관한다. 연결 준비 실패도 그 시도 대상에만 적용한다. 재시도 시작을 성공으로 처리하지 않으며, 성공한 항목의 오류만 지운다. 네트워크/인증/충돌/계약 검증/기타 오류를 예외 타입으로 구분하며 표시 문구를 파싱하지 않는다. 일반 IOException은 네트워크 오류로 단정하지 않는다.

기존 전사·노트가 있으면 본문을 계속 표시하고 오류 안내를 함께 제공한다. 재시도는 기존 작업 잠금을 사용하며 상태 버튼도 작업 중 비활성화한다. 동기화 중 표시는 실제 시도 대상에만 적용한다. 인증/설정 오류는 기존 연결 설정으로 안내한다.

새 오류 분류는 세션 상태다. 프로세스 재시작 후에는 다음 실제 동기화에서 다시 판단한다. 저장된 기존 status 문자열과 녹음/결과/클라우드 계약은 유지하며, 상세 진단에서 기존 상태를 확인할 수 있다.

## 검증과 한계
- 앱 APK·단위 테스트54개·lint 오류0/경고32·계측 APK 컴파일 통과. UI 계측은 실행하지 않았다.
- 새 테스트3개는 녹음별 오류 격리, 재시도/성공/종료 상태, 사전 연결 실패 대상 제한, 예외 분류를 확인한다. 최초 실행은 새 타입 미구현으로 컴파일 실패했고 구현 후 통과했다. 원래 UI 오류를 실제 클릭으로 재현한 테스트는 아니다.
- 첫 중간 빌드는 수정 중 lint의 SuspiciousIndentation 오류2개를 보고했다. 코드 동결 후 최종 전체 빌드에서는 오류0으로 통과했다. 편집/분석 시점 영향은 추정이며 독립 재현하지 않았다.
- CUA는 Sky Computer Use native pipe startup failed로 연결되지 않았다. 실제 픽셀 일치, 작은 화면/큰 글꼴/TalkBack·클릭·네트워크 실연결 검증은 미완료다.
- Team1 구현2명·Team2 검토1명이 응답/수정 없이 대기해 종료한 뒤 root가 직접 수정했다. 이번 변경에 대한 독립 검토 완료를 주장하지 않는다.
- Android 다중 선택/휴지통/폰 내 AI와 전체 Markdown 등 앞선 별도 기능 범위는 이번에 추가하지 않았다.
