# Vemo Windows functional preview

The user explicitly authorized unattended functional implementation through Windows, installation and emulator/VM testing. Design is assigned elsewhere; preserve existing assets/layout concepts and do not redesign. Ask only for unavoidable user authentication. Root owns integration, infrastructure, actual cloud/device tests and NAS publication.

## Scope and architecture

Create a native Windows desktop executable with a testable .NET 10 core and a thin Avalonia shell. Use existing folder/list/detail layout and approved icon; system controls are sufficient. The current Python engine contains macOS MLX and POSIX storage/process assumptions. Keep it intact and implement a Windows-specific queue/backend using the same mobile v1 wire contract. This costs duplicate orchestration code but avoids weakening existing data safeguards or pretending MLX runs on Windows.

Implement local audio import, durable queued processing with cancellation/retry, title/date preservation and inline rename, transcript and study-note output, folders/subfolders and move, multi-selection/trash/restore/purge of owned data only, automatic three-file ZIP exports mirroring library folders. Local sources and exported archives must survive library delete/purge. Settings select output folder, model files/runtime executables and CPU/CUDA mode. Preserve completed results across restart and model setting changes. Add a watched mobile sync folder using processor.json / recordings / results contract from 2026-10-17 spec. Malformed/partial/wrong-processor/hash-mismatched requests fail independently and do not appear completed. Original recorded_at and timezone are preserved. ZIP contains exactly original.<ext>, transcript.txt, notes.md, title/date filename without hashes and safe collision suffix.

Inference uses local whisper.cpp (Korean-first transcription) and llama.cpp (structured detailed notes) executables, passed arguments without a shell, network-free local models, subprocess cancellation tree and bounded timeout/output. User explicitly downloads selected pinned models; inference never silently downloads. Initial profiles: Whisper small / large-v3-turbo and Qwen3.5 9B / 27B GGUF. Verify actual repo revisions and release binaries before pinning; model availability is different from measured quality. CPU support is required; CUDA only when the chosen runtime and device support it. 5070Ti 16GB does not imply full 27B GPU residency. RAM/VRAM recommendations are estimates and model selections are captured per job. Tests may inject tiny/mock inference but must not call that actual model quality verification.

Notes must summarize by topic with conditions/examples, not concatenate key sentences. Use source-numbered JSON and validate refs/schema; preserve ASR when notes fail. No invented success/percentages. Unsupported/absent models are explicit recoverable states. No built-in credentials, no generic shell-command setting, no arbitrary URL execution.

Desktop Google OAuth is a subsequent independent adapter in this same work phase if feasible; local folder support must be usable first and must not be advertised as drive.file automatic API roundtrip. Android/Mac existing direct OAuth remains intact. Do not copy Mac tokens or client secrets into Windows artifacts.

## Validation / acceptance

Core tests run natively on Mac/Linux and cover persistence/recovery, ownership/path traversal/reparse/symlink rejection, deletion/zip collisions, paused versus complete input, model selection snapshots, cancellation, invalid notes, mobile identity/date/hash checks. Build Windows x64 and ARM64 self-contained outputs and inspect signatures/hashes/dependencies. Attempt Windows VM using official media and existing/free tools; no paid license/subscription, no changes to shared host services. State precisely if only compilation or compatibility runtime is achieved. Actual Nvidia execution remains pending until target PC is available.

For Mac/Android, finish real spoken test-audio ASR+notes and return, using existing isolated test root and synthetic speech (no private conversations). Do not use synthetic transcript as inference evidence. Existing public Mac build24 fixes/icon must be carried forward. Any macOS installation keeps stable signing and rollback backup, waits for active inference to finish, and does not overwrite another session's design edits.
